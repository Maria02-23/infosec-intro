## Установка имени пользователя и хоста

1. Запустите терминал и получите полномочия администратора:
su -. 

![Режим администратора](image/3.1.jpg){#fig:015 width=70%}

2. Создайте пользователя (вместо username укажите ваш логин в дисплейном классе):
adduser -G wheel username

![Создаём нового пользователя](image/3.1.jpg){#fig:016 width=70%}

3. Задайте пароль для пользователя (вместо username укажите ваш логин
в дисплейном классе):
passwd username

![Задаём пароль для добавленного пользователя](image/3.1.jpg){#fig:017 width=70%}

4. Установите имя хоста (вместо username укажите ваш логин в дисплейном классе):
hostnamectl set-hostname username

![Устанавливаем имя хоста](image/3.2.jpg){#fig:018 width=70%}

5. Проверьте, что имя хоста установлено верно:
hostnamectl

![Проверяем новое имя хоста](image/3.2.jpg){#fig:019 width=70%}

6. Перезапускаем и видим, что появился новый пользователь - он настроен верно!

![Появился новый пользователь](image/3.3.jpg){#fig:020 width=70%}

## Ответы на контрольные вопросы


1. Учётная запись пользователя
Учётная запись пользователя в операционной системе Linux включает следующую информацию:

Имя пользователя — уникальное имя, которое используется для входа в систему.
Пароль — ключ безопасности для защиты аккаунта от несанкционированного доступа.
UID (User ID) — уникальный числовой идентификатор пользователя.
GID (Group ID) — числовой идентификатор группы, к которой принадлежит пользователь.
Домашний каталог — директория, где хранятся личные файлы пользователя.
Командный интерпретатор (shell) — программа, выполняющая команды пользователя.
Эта информация хранится в файлах /etc/passwd и /etc/shadow.

2. Команды терминала
– Для получения справки по команде:

man команда
Пример:


man ls
– Для перемещения по файловой системе:

cd путь_до_каталога
Пример:


cd ~/Документы
– Для просмотра содержимого каталога:

ls [опции]
Пример:


ls -l
– Для определения объёма каталога:

du -sh каталог
Пример:


du -sh ~/Загрузки
– Для создания / удаления каталогов / файлов:

mkdir имя_каталога   # создание каталога
touch имя_файла      # создание файла
rm имя_файла         # удаление файла
rmdir имя_каталога   # удаление пустого каталога
rm -rf имя_каталога  # удаление каталога с содержимым
Примеры:


mkdir новая_папка
touch новый_файл.txt
rm старый_файл.txt
– Для задания определённых прав на файл / каталог:

chmod права файл_или_каталог

– Для просмотра истории команд:

history
Пример:

history | tail -n 10  # просмотр последних 10 команд
3. Файловая система
Файловая система — это способ организации хранения и управления данными на носителе информации (например, жёстком диске). Она определяет структуру размещения файлов и папок, способы именования объектов, методы записи и чтения данных.

Примеры файловых систем:

ext4 — стандартная файловая система для Linux, поддерживает журналирование, большие объёмы данных.
NTFS — файловая система Windows, поддерживает большие размеры файлов и диски.
FAT32 — старая файловая система, совместимая с разными операционными системами, ограничена размером диска до 8 ТБ.
XFS — высокопроизводительная файловая система с поддержкой больших объёмов данных и параллельных операций ввода-вывода.
4. Просмотр смонтированных файловых систем
Для просмотра всех подмонтированных файловых систем в Linux используют команду mount. Например:


mount
Она покажет список всех монтированных устройств и точек монтирования.

Другой вариант — использовать команду df, чтобы увидеть свободное пространство и точки монтирования:


df -h
5. Удаление зависшего процесса
Чтобы удалить зависший процесс, нужно сначала определить его PID (идентификатор процесса), используя команду ps или top:


ps aux | grep название_процесса
Пример:


ps aux | grep firefox
Затем убить процесс командой kill:


kill PID
Если процесс не отвечает, можно использовать сигнал принудительного завершения (SIGKILL):


kill -9 PID
